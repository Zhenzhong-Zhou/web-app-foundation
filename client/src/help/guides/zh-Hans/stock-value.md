# 库存价值

现有库存值多少钱，以本位币计。每个批次记录其成本；无批次的库存采用移动平均成本。价值仅为物料成本：采购的，以及投入生产批次的。

## 为库存设定成本 {#costs}

到货时没有估值依据的库存列在**等待成本**下，**原因**说明缺少什么：收货时没有价格、以没有登记汇率的币种计价、盘盈入库，或开始估值时已有的库存。在设定成本之前，现有库存的价值为**暂估**。

1. 在该行上，点**设定成本**。
2. 输入**单价**，即供应商的每件计价，以及它的**币种**。
3. 如果不是本位币，输入**汇率**，或留空以使用到货当天已登记的汇率。
4. 点**设定成本**。

由仍未关闭的生产订单生产的批次，则等待其生产订单：点**打开生产订单**前往，批次会在生产订单关闭时得到成本。

> 只有可以修改成本的人才看得到**设定成本**。

## 查看价值 {#read}

总额显示在**现有**旁。**按物品和批次**列出每个物品和批次的数量、**单位成本**和**价值**；点批次编码可打开它的追溯。**导出**会把列表下载为电子表格文件。

## 常见词 {#words}

- **本位币**：库存估值所用的币种，在组织的**财务**标签页中设置。
- **暂估**：其中仍包含等待成本的库存的价值。
- **单位成本**：一个单位的价值，即价值除以数量。

## 被拒绝时 {#refused}

- 尚未设置本位币，因此无法计算价值。请在[组织](/settings/organization)中设置。
- 到货当天或之前没有已登记的汇率。请在[汇率](/settings/exchange-rates#add)中录入一个，或随成本提供汇率。

另见[汇率](/settings/exchange-rates)。
