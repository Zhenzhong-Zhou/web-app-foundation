# 首页

首页是您登录后看到的第一个页面。它告诉您今天有多少事项需要处理，提供您最常用的操作，并按类别列出等待处理的工作。显示的内容取决于您在这里可以做什么。

## 您的头两周 {#welcome}

您刚加入时，首页最上面是一张属于您的欢迎卡片：邀请人的留言、您在这里可以做什么，以及您的第一周。第一周的每一项都在您做完后自动打勾，不能手动勾选；每项的按钮会带您去完成它的地方。

1. 如果邀请人留了言，先读一读。
2. 逐项完成您的第一周；如果列出了确认电子邮箱，请先确认。
3. 不再需要这张卡片时，点**隐藏**。片刻之内可以点**撤销**把它找回来。

每一项都完成后，或加入满两周时，卡片会自动消失，卡片上写明是哪一天。您在这里可以做什么，会一直保留在[我的账户](/account#your-access)里。

## 入门指引 {#getting-started}

新组织的首页不是一页零，而是七个步骤。每一步都根据组织里已有的内容自动打勾：

1. **您的组织**：开票需要的地址、税号和币种。
2. **添加库位**：存放库存的地方。
3. **添加产品**：您采购、生产或销售的物品。
4. **添加合作伙伴**：客户或供应商。
5. **收货入库**：这样才有可发的货。
6. **发货并开票**：完整走一遍流程。
7. **邀请团队成员**：这一步可以跳过。

> 只有可以修改组织设置的人才看得到这里的**隐藏**和**跳过**，只有可以邀请的人才看得到**邀请同事**。

## 需要处理的事项 {#attention}

- 这些数字告诉您有多少事项在等您，其中多少已逾期或已过期。
- 每张卡片列出最紧急的几项，例如**待发货**、**待收货**或**即将过期**。点**查看全部**打开完整列表。
- **最近打开**带您回到最近打开过的内容。

首页在您打开时读取。点**刷新**重新读取。

## 不在任何组织中时 {#no-organization}

请组织里的人邀请您的邮箱，然后在登录状态下打开对方发来的链接：您会用这个账户加入。创建您自己组织的链接，也是这样打开。如果首页提供**创建组织**，您也可以在那里创建一个，并成为它的所有者。

## 常见词 {#words}

- **逾期**：已过了预计或到期的日期。
- **即将过期**：在组织设定的天数内会过期的批次。
