# Emplacements

Les emplacements sont les endroits où le stock est gardé, d’un site entier jusqu’à un casier. Ils forment un arbre, et le stock se trouve seulement dans un emplacement qui n’en contient aucun autre.

## Ajouter un emplacement {#add}

1. Appuyez sur **Ajouter un emplacement** pour un emplacement au niveau supérieur, comme un site, ou sur **Ajouter à l’intérieur** sur un emplacement pour en ajouter un dedans.
2. Choisissez son type : un site, une zone, une allée, une tablette ou un casier. C’est une étiquette pour la lecture, pas une règle.
3. Donnez son nom, et son code tel que sur l’étiquette, comme A-01-03. Un code n’est utilisé qu’une fois dans le même emplacement.
4. Appuyez sur **Ajouter un emplacement**.

Une seule pièce peut être un emplacement à part entière : vous pourrez y ajouter des casiers plus tard au besoin.

## Donner une adresse à un site {#address}

Appuyez sur **Adresse** sur un site pour dire où il se trouve. Les bons de commande demandent de livrer là, et les retours y sont renvoyés. Sans adresse, ils impriment l’adresse du siège de l’organisation. Les emplacements à l’intérieur d’un site partagent son adresse.

## Modifier ou retirer un emplacement {#edit}

1. Appuyez sur **Modifier** sur l’emplacement.
2. Changez son nom, son code, ou l’emplacement dans lequel il se trouve, sous **Dans**.
3. Désactivez **Disponible pour la préparation des commandes** pour du stock qui ne doit pas partir, comme des retours à vérifier.
4. Désactivez **En usage** pour le retirer. Un emplacement est retiré plutôt que supprimé, pour que son historique reste.
5. Appuyez sur **Enregistrer**.

> Seule une personne qui peut ajouter des emplacements voit **Ajouter un emplacement**, et seule une personne qui peut les modifier voit **Ajouter à l’intérieur**, **Adresse** et **Modifier**.

## Les mots que vous verrez {#words}

- **Site**, **Zone**, **Allée**, **Tablette** et **Casier** : le type d’un emplacement, du plus extérieur au plus intérieur.
- **Contient du stock** : un emplacement qui n’en contient aucun autre, où le stock peut se trouver.
- **Non disponible** : son stock n’est pas à expédier.
- **Retiré** : plus en usage, conservé pour son historique.

## Si quelque chose est refusé {#refused}

- On ne peut pas ajouter un emplacement dans un emplacement qui contient du stock. Déplacez d’abord son stock vers un autre emplacement.
- Un code déjà utilisé dans le même emplacement est refusé. Choisissez-en un autre.
- Un emplacement ne peut pas être déplacé à l’intérieur de lui-même ni de ce qu’il contient.
