# Licences

Les licences sont les numéros sous lesquels vos formulations sont enregistrées, comme le NPN d’un produit de santé naturel au Canada. Les recettes sont fabriquées sous ces licences : un lot remonte donc jusqu’à sa licence. Vous arrivez à cette page par **Licences**, dans Produits.

## Ajouter une licence {#add}

1. Appuyez sur **Ajouter une licence**.
2. Saisissez le numéro tel que délivré, et qui l’a délivré, comme Santé Canada.
3. Indiquez la date à laquelle elle a été délivrée, si vous l’avez.
4. Laissez **Valide jusqu’au** vide pour un régime sans expiration. Un NPN n’expire pas.
5. Appuyez sur **Enregistrer**.

Choisissez-la ensuite sur une recette, sous **Licence**.

## La garder à jour {#current}

1. Appuyez sur **Modifier** sur la licence.
2. Changez **Valide jusqu’au** quand elle est renouvelée, ou désactivez **En vigueur** quand elle est retirée.
3. Appuyez sur **Enregistrer**.

Les licences retirées et expirées restent dans la liste, pour qu’un lot fabriqué sous l’une d’elles reste traçable. Les nouvelles recettes cessent de proposer une licence retirée.

Les personnes qui peuvent modifier les licences ou lancer des ordres de fabrication sont averties dans la cloche 60, 30 et 7 jours avant l’expiration d’une licence, puis le jour même. Ce qu’un ordre de fabrication fait d’une licence expirée est le choix de votre organisation : voyez sa [politique des licences](/settings/organization#licences).

> Seule une personne qui peut ajouter des licences voit **Ajouter une licence**, et seule une personne qui peut les modifier voit **Modifier**.

## Les mots que vous verrez {#words}

- **En vigueur** : valide aujourd’hui.
- **En vigueur à partir du** : délivrée à compter d’un jour à venir, et utilisable à partir de ce jour.
- **Expire dans** : à moins de 60 jours de sa date **Valide jusqu’au**.
- **Expirée** : sa date **Valide jusqu’au** est passée.
- **Retirée** : plus utilisée, conservée pour ce qui a été fabriqué sous elle.

## Si quelque chose est refusé {#refused}

- Un numéro déjà enregistré pour le même organisme est refusé. Modifiez celui qui est déjà dans la liste.
- Une licence ne peut pas expirer avant d’avoir été délivrée. Vérifiez les deux dates.
