# Journal d’audit

Le journal d’audit liste chaque modification faite dans cette organisation, de la plus récente à la plus ancienne : ce qui a été fait, à quelle fiche, par qui, quand et d’où. Les entrées sont conservées deux ans, et personne ne peut les modifier ni les supprimer.

## Trouver une modification {#find}

1. Choisissez une **Action**, ou gardez **Toutes les actions**.
2. Indiquez des dates dans **Depuis** et **Jusqu’au** pour limiter la liste à une période.
3. Appuyez sur **Afficher plus** pour les entrées plus anciennes.

Quand une entrée présente un champ avec une flèche, la valeur est passée de la première à la seconde; une seule valeur indique celle qui a été donnée au champ. Une entrée de deux modifications ou plus montre chacune sur sa propre ligne, le champ avec son ancienne valeur → sa nouvelle, après une première ligne qui réunit les détails qui ne sont pas des modifications, comme la fiche. À partir de sept modifications, elle montre les cinq premières, avec **Afficher les 7 modifications** pour ouvrir le reste sur place et **Afficher moins** pour le refermer. Rien n’est coupé, et l’**Historique** d’une fiche se lit de la même façon. **Exporter** télécharge au format CSV les entrées correspondant à vos filtres.

## Une fiche, ou une personne {#record}

- **Historique**, sur la page d’une fiche, montre ses modifications récentes à côté d’elle, et ouvre les autres ici.
- La page d’une personne dans [Personnes](/people) ouvre ici toute son activité.

Le journal dit alors qu’il ne montre qu’une fiche, ou qu’une personne. **Tout afficher** revient à tout.

> Seule une personne qui peut lire le journal d’audit voit cette page, et **Historique** sur les fiches.

## L’entrée d’un lot {#lot}

« Lot modifié » nomme le lot et son article, et garde chaque champ que l’enregistrement a changé, avant → après : le code de lot, le lot du fournisseur, le genre de date de péremption et son jour. Un code corrigé garde les deux, « Code de lot : ASH-06O1 → ASH-0601 ». Pourquoi le code a changé n’est pas écrit ici : c’est conservé avec l’ancien code sous **Anciens codes**, sur la page du lot, aussi longtemps que le lot, alors que le journal garde ses entrées deux ans. Voir [Tracer un lot](/lots#code).

## Votre propre activité {#yours}

Chaque personne peut voir ce qu’elle a fait elle-même : **Voir tout votre travail** dans [Votre compte](/account). Vos connexions et changements de mot de passe sont dans **Vos appareils**.

## Les mots que vous verrez {#words}

- **Par** : le membre qui a fait la modification.
- **Un compte supprimé** : une personne dont le compte a été supprimé. Ce qu’elle a fait reste dans le journal.

## Si quelque chose est refusé {#refused}

- Sans accès, la page dit que vos rôles ne donnent pas accès au journal d’audit. Demandez à quelqu’un qui peut changer les rôles.

Voir aussi [Personnes](/people).
