# Tax codes

Every invoice line carries a tax code, which says what tax it charges. A code can charge two taxes on the same amount, such as GST and PST together; a code that charges nothing is exempt.

## Add a tax code {#add}

1. Press **Add tax code**.
2. Give it a **Name**, as the invoice line will show it: GST, GST + PST (BC), Exempt.
3. Under **Taxes it charges**, press **Add a tax** for each tax, with its name and **Rate %**. Leave none for a code that charges nothing.
4. Press **Save**.

Add the taxes you charge, and an Exempt code for items you do not tax: no invoice is issued until each of its lines has a code.

## Change or retire a code {#change}

1. On the code’s row, press **Edit**.
2. Change a rate, or untick **In use** to retire the code.
3. Press **Save**.

A new rate applies to invoices issued afterwards; those already issued keep the rate they were issued with. A retired code stays on the invoices that used it, and is no longer offered for new lines.

> Only someone who may add tax codes sees **Add tax code**, and only someone who may change them sees **Edit**.

## Words you’ll meet {#words}

- **In use**: offered on new invoice lines.
- **Retired**: kept on past invoices, offered on no new ones.
- **Exempt**: a code that charges nothing.

## If something is refused {#refused}

- A tax code with that name already exists. Choose another name, or edit the one there.
- A tax is listed twice. A code charges each tax once.
- A rate is a percentage between 0 and 100.
- An invoice line has no tax code. Choose one, or Exempt, on the invoice.
