PUT /v1/products/{id}/images the `fileIds` request property's maxItems was set to `8` -- the limit held already, @ArrayMaxSize refusing a ninth; @nestjs/swagger 12.0.3 now writes it into the document.
PUT /v1/products/{id}/translations the `translations` request property's maxItems was set to `3` -- the limit held already, @ArrayMaxSize refusing a fourth language; @nestjs/swagger 12.0.3 now writes it into the document.
PUT /v1/products/{id}/variants/{variantId}/translations the `translations` request property's maxItems was set to `3` -- the limit held already, @ArrayMaxSize refusing a fourth language; @nestjs/swagger 12.0.3 now writes it into the document.
POST /v1/files/logo added the new `square_logo` enum value to the `file/kind` response property for the response status `201` -- each upload route returns only its own kind, so this one still returns only `logo`; `square_logo` comes only from the new POST /v1/files/square-logo, which no open tab calls (ADR-060, amended).
POST /v1/files/product-image added the new `square_logo` enum value to the `file/kind` response property for the response status `201` -- as above: this route still returns only `product_image`, and no open tab calls the square logo's (ADR-060, amended).
